CSRF Attack ? Cross-Site Request Forgery
A web browser stores the JSessionId in the cookie.
CSRF Token -> is a unique value that has to be sent in request headers in addition to the sessionId.
In this defense, when the server serves a page, it embeds an unpredictable value in the page, called the CSRF token.
It is not saved in cookies.
