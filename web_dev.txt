👀 Introduction to JavaScript
JS functions and events are the building blocks of interactivity in web development.
A function is a reusable block of code.
A function performs a specific task.
Functions can take input (called parameters) and produce outputs known as return values.

****************************************************************************************************
function addNums(a,b){
return a+b;
}

let sum=addNums(3, 5);
console.log(sum);
****************************************************************************************************

What is the event handling? JavaScript detects and responds to user actions, like submitting a form, clicking a button.

✅ Arrays and objects
Arrays and objects are 2 fundamental data structures in JS.
Arrays act like organized lists where each item has a specific order.
Objects store data in key-value pairs.

Create an array in JS
let cars=["nissan", "mustang" "toyota"];
or
let cars=new Array("nissan", "mustang", "toyota"]; // it's less commonly used.
console.log(cars[0]); // accessing an element
